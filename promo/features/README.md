# KVFX Tools: top ten Tools features

Ten short videos, one per feature, in two formats each:

* **16:9** for YouTube: the KVFX panel on the left, the comp on the right.
* **9:16** for Shorts, Reels and TikTok: the comp on top, the panel below it.

Each video is about 28 seconds long. It opens on a title card, shows the
feature at work with captions, and closes on an end card that names the next
video. The captions carry the whole explanation, so the videos work with the
sound off.

| # | Feature | Where it lives |

## What's in the frame

* **The panel** is a real recording of the built panel. The cursor clicks each
  control once, as the caption names it. The panel window follows the cursor,
  so in the narrow 9:16 window the control in use is always in view.
* **The comp** is an animated After Effects-style viewer, drawn by
  `scenes.mjs`. It is not a screen recording of After Effects. Each scene
  follows the shipped code exactly:
  * Even Gaps keeps the first layer and shares the span.
  * Align as Group moves the selection's bounds as one block.
  * Sequence ranks centre-out by distance from the middle.
  * Comp Resizer's Fit scales by the smaller ratio around the pinned spot.
  * Follow adds the leader's change since the click, delayed.
  * The anchor grid moves the anchor and compensates the position.
* **The sound** is generated by the renderer, so nothing licensed is needed: a
  soft click on every click in the recording, and a whoosh into and out of the
  demo. Put one licensed track in `assets/music` and it is mixed in underneath
  every video at a low level.

## Files

| File | What it is |
|---|---|
| `features.mjs` | One source of truth: each recording's cursor path and clicks, each video's captions and the click times its scene reacts to. |
| `scenes.mjs` | The ten comp scenes. Each is a pure function of time. |
| `studio.html`, `studio.mjs` | Draws any frame of any video, in either format. |
| `assets/clips/tf-*.mp4` | The panel recordings at 2× (760 × 1720, 30 fps). |
| `assets/clips/tf-*.json` | Each recording's cursor path and click times. |
| `../../scripts/feature-videos.mjs` | Renders the MP4s. |

## Render

```
npm run build && node scripts/preview.mjs --all --width 380
node scripts/promo-capture.mjs --clip tf-resize,tf-follow     # re-record panels (--dry checks targets)
node scripts/feature-videos.mjs                               # all ten, both formats
node scripts/feature-videos.mjs --only follow --layout 9x16
node scripts/feature-videos.mjs --stills 4,12 --only follow   # PNG stills for a quick look
```

The scripts need Playwright (`KVFX_PLAYWRIGHT`), Chromium (`KVFX_CHROMIUM`)
and ffmpeg (`KVFX_FFMPEG`, or ffmpeg on PATH). The titles use the Unbounded
font from Google Fonts. Without a connection they fall back to Inter Display.

The videos are written to `build/feature-videos/NN-<feature>-<16x9|9x16>.mp4`:
H.264 High at CRF 16 and 30 fps, with AAC audio at 192 kbps.

## Changing a video

* **Words.** Edit the captions in `features.mjs`. Times are seconds into the
  panel recording.
* **Clicks.** Each feature's click times are named once in `features.mjs`.
  The recording and the scene both read them, so they stay in step. Record the
  clip again after changing them.
* **The comp.** Edit the feature's scene in `scenes.mjs`, then check a few
  stills.

## Posting

* **YouTube:** upload the 16:9 files. Use the end card's "Next" as an end screen
  pointing at the next video, and put the ten in a playlist in this order.
* **Shorts, Reels and TikTok:** upload the 9:16 files. Nothing important sits
  in the bottom fifth of the frame, where those apps place their own buttons
  and captions.
